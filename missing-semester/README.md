# MIT Missing Semester 学習ログ

[← 学習ログのトップへ](../README.md)

MIT の講座「The Missing Semester of Your CS Education」2020年版（日本語訳）の学習記録です。
シェル・エディタ・Git など、授業では教わらない道具の使い方と、その裏で何が起きているかを学んでいます。

## 進め方
- Claude を講師役にして、資料の解説・確認問題・演習の添削を受けながら進めています
- 演習は自分の WSL 環境で手を動かし、最後に行数や数値で結果を確かめる形を中心にしています
